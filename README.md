# Proyecto pintura PR2 - 2026

Proyecto de la asignatura "Proyecto II" sobre la automatización del rellenado de botes de pintura

Instrucciones para la correcta configuracion de RoboDK:
    - Primero: Descargar el comprimido '.zip' adjunto (pintproyecto). Descargar tambien el archivo estación de RoboDK.
    - Segundo: Ir al directorio principal de RoboDK y situarte en su carpeta ‘python’ (normalmente la ruta estándar es: “<disco_local>\RoboDK\python”. Ej: “C:\RoboDK\Python”). Una vez en esta carpeta, descomprimes el archivo. Debería aparecer un nuevo directorio/carpeta “pintproyecto”, en su interior únicamente deberia aparecer archivos/scripts python (.py).
    - Tercero: La configuración en si ya estaria completa, solo quedaria abrir el archivo estacion de RoboDK. Para iniciar la simulación se debará usar exclusivamente el script que viene incluido llamado "main". Una vez ejecutado solo necesitaras realizar un pedido para que empiece la simulacion.
